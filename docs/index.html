How the pieces connect

The same four steps run on the real hardware and in this site's simulation.

Measure

A solar ESP32 station reads two soil probes, air temperature and its battery every 15 minutes, and keeps readings if the network drops.

See it: Hardware lab, or open a station in the 3D twin

Collect

Readings travel over Wi-Fi or 4G to a gateway: a Raspberry Pi on the farm, or any server.

See it: data dots flying to the gateway in the 3D twin

Decide

The advisor tracks the root-zone water balance (FAO-56) against the rain forecast and works out pump minutes.

See it: soil water charts in the Live dashboard

Advise

The farmer gets one clear WhatsApp message, or the pump relay switches automatically, with a safety cap.

See it: the WhatsApp feed in the Live dashboard

3. Real station

A solar ESP32 with two capacitive soil probes, a BME280 and an optional pump relay. Roughly ₹2,000–3,500 in parts.

The virtual board

diagram.json wires the Wokwi ESP32 like the field station.

The virtual board reads every 15 seconds instead of 15 minutes, and each pump minute lasts one second.

Run it in VS Code

  1. Open the repo in VS Code and install the recommended extensions: Wokwi Simulator, PlatformIO and Python.
  2. Get a free Wokwi licence for open-source projects: press F1 and choose Wokwi: Request a new License.
  3. Build the firmware for the virtual board:
    cd firmware && pio run -e wokwi
  4. Start the server the board will talk to:
    cd server && python -m krishisense --config stations.wokwi.json --db wokwi.db serve
  5. Open diagram.json, press F1 and choose Wokwi: Start Simulator. Then open localhost:8080 and slide the probes up to dry the soil.

Run the Python simulation

The same three farms, with the real server and dashboard on your computer.

cd server && pip install -e ".[dev]"
python -m krishisense sim --days 14 --speed 3600
pytest -q
