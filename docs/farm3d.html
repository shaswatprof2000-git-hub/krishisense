How KrishiSense decides when to water

Each field has a solar sensor station. Everything below runs in this page, the same way it runs on the real hardware and server.

Measure

An ESP32 reads two soil probes (15 cm and 30 cm), air temperature and battery every 15 minutes. If the network is down it keeps up to 96 readings in memory.

Collect

Readings travel over Wi-Fi or 4G to a gateway (a Raspberry Pi or any server), which stores them with the rain forecast.

Decide

FAO-56 water balance: the root zone stores TAW; stress starts once RAW = p × TAW is used. Crop use per day is Kc × ET0. Likely rain can cancel watering.

Advise

The farmer gets one WhatsApp message in Odia, Hindi or English with pump minutes. With an automatic pump, the relay runs it, capped for safety.
